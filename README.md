# Oasis Android

Android Studio project for the Oasis mobile app.

## Project

- App name: Oasis
- Package: `com.oasis.mobile`
- Pattern: MVP-style screens adapted for Oasis
- Main source: `app/src/main/java/com/oasis/mobile`
- Current screens from the reference template:
  - `screens/login`
  - `screens/home`
  - `screens/profile`

## Open In Android Studio

1. Open Android Studio.
2. Choose **Open**.
3. Select `C:\Users\MY PC\OasisProject\oasis-android`.
4. Let Android Studio sync Gradle.

The first sync may download Gradle and Android dependencies.
